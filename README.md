# ETF Lab

基于 AkShare 的本地 ETF 回测工作台。它将 ETF 目录缓存到 SQLite，并将每只基金的历史收盘价缓存为 CSV；首次成功拉取后，后续搜索和已覆盖区间的回测无需重复下载目录或价格数据。

## 已实现能力

- ETF 名称或代码模糊检索，目录默认每日自动更新，也可在界面手动刷新。
- 多基金目标权重组合，支持周初/周末、月初/月末、季初/季末的首个或最后一个交易日再平衡。
- 定投：按固定金额按权重买入，或对每只基金按固定份额买入。
- 定投频率和定投后再平衡均可选择周初/周末、月初/月末、季初/季末；首末均按对应周期的实际交易日计算。
- 手续费、累计投入、时间加权收益、年化收益、年化波动、夏普比率、最大回撤、期末持仓和逐笔交易流水。
- 行情优先使用 AkShare 东财前复权日线；东财不可用时自动切换到 AkShare 新浪 ETF 日线。回测采用可交易份额的连续近似，未引入最小申报单位、滑点、税费或停牌交易限制。

## 运行

需要 Python 3.10+。在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

访问 `http://127.0.0.1:8000`。

首次打开时应用会通过 AkShare 拉取完整 ETF 目录，优先使用东财接口；东财不可用时会自动切换到新浪 ETF 目录接口。如果所有 AkShare 上游临时不可访问，界面才会使用一组本地常用 ETF 作为搜索兜底；点击右上角刷新可再次请求完整目录。每次回测会优先复用 `data/cache/prices/` 中已经覆盖日期范围的行情。

## 测试

```powershell
python -m pytest -q
```

测试使用合成价格序列，不依赖网络或 AkShare 上游状态。

## 项目结构

```text
app/
  data.py       # AkShare 适配、ETF 目录 SQLite 缓存、行情 CSV 缓存
  backtest.py   # 再平衡和定投回测引擎
  main.py       # FastAPI API 与静态页面服务
  static/       # 操作界面
tests/          # 回测引擎单元测试
data/           # 首次运行后生成，不纳入 Git
```

## 数据与风险提示

本项目用于策略研究与历史模拟，不构成任何投资建议。历史表现不代表未来结果；正式交易前应另行评估真实成交成本、最小交易单位、流动性、停牌、分红税务和跟踪误差等因素。
