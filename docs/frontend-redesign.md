# ETF Lab 前端重设计

## 设计与改动边界

采用深蓝导航（#122b49）、浅灰蓝画布（#f3f6fa）、白色卡片与蓝色主操作（#0079c2）。收益红涨绿跌；状态成功、警告、错误分别使用语义颜色。保留东吴证券原始 logo 文件，资源失败时显示文字标识。

信息结构调整为：组合配置、回测概览、基金表现、交易流水。参数面板分为基金与权重、策略与区间、资金与执行；桌面端仅表单内部滚动，运行按钮保留在面板底部。短屏回退为普通页面滚动，避免内容不可达。支持收起参数专注结果、权重分布、运行中状态、结果生成后解锁导航、窄屏局部表格滚动、可见键盘焦点及减少动画偏好。

`styles.css` 整体替换旧主题，不在旧样式之后堆叠覆盖；`workspace.js` 仅负责界面增强，不请求接口，也不修改回测参数或指标。图表配色继续与原有业务脚本一致，布局改变时通过 ECharts 实例的 resize 调整尺寸。

原有 `app/static/app.js` 逐字节保持不变，其 Git blob SHA 为 `6fc16a9efe88abe70820ae81a6dacbf7baddfb8f`。后端、API 契约、行情获取、成交与指标计算、依赖版本均未变更。页面初始状态没有模拟收益，插图明确标注为示意。

## 可复现验证

前端无打包步骤。在项目环境中执行：

```bash
node --check app/static/app.js
node --check app/static/workspace.js
python -m pip install pytest playwright
python -m playwright install chromium
python -m pytest tests/test_frontend.py -q
```

已有 Chromium 时可设置 `UI_CHROMIUM_PATH` 指向可执行文件。未安装 Playwright 时该测试模块明确跳过，不能将跳过视为通过。

本次本地 Chromium 验证：19 项通过。测试直接加载仓库 HTML/CSS/JS，不开启网络连接；API 由确定性 fetch 替身提供，ECharts 替身记录初始化、选项和 resize 调用。覆盖 DOM 契约、ETF 增删、权重校验、定投参数完整性、运行中状态、指标/持仓/流水渲染、失败恢复、导航与参数收起、图表资源缺失、减少动画、空组合，以及 320/390/600/768/980/1024/1250/1280/1440/1920 像素宽度。检查页面无横向溢出，常规桌面高度下运行按钮可见。
